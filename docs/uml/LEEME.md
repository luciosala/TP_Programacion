# Diagramas por tema (Entrega 2)

Un diagrama por tema, para la presentación. El fuente de cada uno es el `.mmd`
(Mermaid) y la imagen el `.png`. El diagrama de clases completo del sistema sigue
siendo `docs/uml-clases.*`.

- `concurrencia.*`: visor del universo paralelo, clases (productor-consumidor con monitor, hilos con Runnable).
- `concurrencia-secuencia.*`: un ciclo del productor-consumidor, con la espera en la plataforma.
- `tablero-elementos-batallas.*`: tablero de la cátedra (versión 2), elementos del universo y batallas (Double Dispatch).
- `login-dao-dto.*`: acceso con DAO y DTO sobre H2.

Para regenerar una imagen a partir del `.mmd` se puede usar https://mermaid.live
(pegar el texto y exportar PNG).
